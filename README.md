# Jasmine 2.0

Executive web presentation for the VTB Jasmine strategy.

## Architecture

Static HTML/CSS/JavaScript only.

- `web/index.html`
- `web/styles.css`
- `web/app.js`
- GitHub Actions → GitHub Pages

No backend, database, API, Vercel, Next.js or external hosting.

Published site:
