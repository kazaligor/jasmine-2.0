03

ДИАГНОСТИКА

Проблема не в отсутствии инструментов. Проблема — в трении между ними.

01 / ФРАГМЕНТАЦИЯ

Разные продукты → разные процессы

Финансирование, размещение и расчёты живут в отдельных контурах.

→ больше посредников
→ выше стоимость обслуживания
02 / МОБИЛЬНОСТЬ КАПИТАЛА

Капитал плохо перемещается

Созданный актив не всегда становится источником следующего финансирования.

→ ниже скорость оборота
→ меньше повторный бизнес
03 / ТРАНЗАКЦИОННЫЕ ИЗДЕРЖКИ

Сделка слишком дорога

Ручные юридические и операционные операции ограничивают частые сценарии.

→ выше ОПЕРАЦИОННЫЕ РАСХОДЫ (OPEX)
→ дороже дистрибуция
04 / СТАНДАРТИЗАЦИЯ

Активы трудно масштабировать

Индивидуальная структура усложняет ценообразование и secondary.

→ слабее ликвидность
→ меньше повторные выпуски
Стоимость создаётся не только при выпуске.
Она создаётся при каждом последующем движении капитала.

05

ЦФА / НЕ ЦФА

Не каждый финансовый продукт должен становиться ЦФА.

ЦФА используются только там, где дают измеримое экономическое преимущество.

ЗАДАЧАТРАДИЦИОННОГДЕ ЦФА МОЖЕТ ПОБЕДИТЬСТАТУС
Corporate financingCredit / bondЛучшая экономика с учётом рискаГИПОТЕЗА
ДЕБИТОРСКАЯ ЗАДОЛЖЕННОСТЬФАКТОРИНГStandardization + дистрибуция + servicingГИПОТЕЗА
финансирование цепочки поставок (SCF)Supply-chain financeПрограммируемость + расчёты + повторяемый потокПРОВЕРКА
Short-term fundingДЕНЕЖНЫЙ РЫНОК / creditСкорость + стандартизацияПРОВЕРКА
ВТОРИЧНЫЙ РЫНОКвнебиржевой рынок (OTC) / существующие рынкиЦифровые расчёты + снижение транзакционных издержекПРОВЕРКА
RWA (активы реального мира) / asset-backedPrivate instrumentsFractional дистрибуция + lifecycleГИПОТЕЗА
ПРАВИЛОЕсли традиционный инструмент даёт лучшую экономика с учётом риска, Jasmine не должна заменять его ЦФА ради самого ЦФА.

07

ЭКОНОМИКА / CONTRIBUTION P&L / ВКЛАД В ПРИБЫЛЬ

Бизнес-модель — монетизация движения капитала, а не комиссия за выпуск.

ПЕРВИЧНЫЙ РЫНОК

Формирование сделок / структурирование

Финансирование, выпуск, размещение.

ВТОРИЧНЫЙ РЫНОК

Торговля / ликвидность

Оборот, брокерские услуги, внебиржевые сделки, маркет-мейкинг.

ФИНАНСИРОВАНИЕ

Повторное использование

РЕПО, финансирование цепочки поставок (SCF), collateral, treasury.

ИНФРАСТРУКТУРА

Сопровождение / данные

Хранение, расчёты, сопровождение, API.

ВЫРУЧКА−ПЕРЕМЕННЫЕ ЗАТРАТЫ−ДИСТРИБУЦИЯ COST−СТОИМОСТЬ РИСКА−СТОИМОСТЬ ЛИКВИДНОСТИ=CONTRIBUTION P&L / ВКЛАД В ПРИБЫЛЬ
КЛЮЧЕВОЙ ОРИЕНТИРContribution P&L / единицу капитала
КОНТРОЛЬДоходность с учётом риска / логика ROE
МАСШТАБИРОВАНИЕПовторные выпуски + оборот на вторичном рынке

ФАКТ / ОЦЕНКА / ЦЕЛЬ: модель — после пилотов, на фактических стоимость обслуживания, risk cost и готовность платить.

РАСПРЕДЕЛЕНИЕ КАПИТАЛА / УПРАВЛЕНИЕ

Jasmine должна управляться как бизнес, а не как технологический проект.

01 / МАСШТАБИРОВАНИЕ

Инвестировать дальше

Положительный contribution P&L, повторяемый спрос, ликвидность, приемлемый risk-adjusted return.

+ повторные выпуски
+ повторные инвестиции
02 / ИЗМЕНИТЬ КОНСТРУКЦИЮ

Менять конструкцию

Рынок и demand есть, но экономику не сходятся.

→ ценообразование
→ структуру
→ сегмент инвесторов
03 / ОСТАНОВИТЬ

Остановить

Слабый спрос + низкая готовность платить + растущий стоимость привлечения клиента (CAC) + высокий регуляторная и риск-нагрузка + отсутствие ликвидность.

→ нет path to positive экономику
04 / ПОСЛЕДОВАТЕЛЬНОЕ ФИНАНСИРОВАНИЕ

Финансировать по доказательствам

Следующий транш зависит от качества новой информации.

PILOT → EVIDENCE → NEXT TRANCHE → МАСШТАБИРОВАНИЕ
Не защищать невозвратные затраты.
Защищать качество следующего решения о капитале.
